# squadUP

squadUP is a React Native Expo app for discovering and creating local activities while meeting new people safely.

## MVP foundation

- Authentication screens for signup and login
- 18+ age verification placeholder in onboarding
- Profile and discover foundations
- React Navigation root, auth stack, and main tabs
- Red, white, and blue brand system with a modern, trustworthy interface

## Getting started

```bash
npm install
npm start
```

## Project structure

```text
src/
  components/     Shared UI building blocks
  hooks/          Reusable app hooks
  navigation/     Root, auth, and tab navigation
  screens/        Auth and main app screens
  services/       API and platform integrations
  theme/          Brand colors and spacing tokens
  types/          Shared TypeScript types
  utils/          Utility helpers
```
